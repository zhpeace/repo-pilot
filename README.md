# RepoPilot · 本地多仓库批量管理工具

一个面向开发者、本地优先的多 Git 仓库批量管理桌面工具（Tauri 2 + Vue 3 + TypeScript）。适合同时维护几十个仓库、被 pull/push 烦到的人。

## 功能

- **仓库总览**：扫描本地根目录下所有 Git 仓库，显示分支、当前分支领先/落后、最后提交时间、脏文件数等状态
- **批量操作**：一键批量 Pull / Push、批量执行自定义命令、批量切换分支，全异步并行执行，带实时进度与结果汇总
- **批量替换 Git 地址**：批量把多个仓库的 remote 从 HTTP 切到 HTTPS（或反向），支持子仓库、自动加协议前缀
- **部分提交**：勾选文件提交，支持暂存/恢复（stash）与备注、提交历史查看
- **克隆新仓库**：输入 URL 自动识别仓库名，超时保护，失败自动清理
- **仓库分组**：左侧树状边栏分组管理，父组聚合过滤
- **权限与安全**：命令超时保护，避免 git 交互认证挂起；401 / 认证失败给出可执行建议
- **多根目录**：支持多个扫描根目录
- **体验**：深色/浅色主题、中/英界面、快捷键（⌘R 刷新 / ⌘⇧A 全选 / ⌘⇧D 深色 / ⌘P 拉取 / ⌘U 推送）、Dock 角标脏仓数、操作日志
- **自动更新**：内置 Tauri 自动更新，发布新版本后应用内一键升级

## 开发

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 开发模式运行
npm run tauri build  # 构建安装包（含自动更新产物）
```

## 系统要求

- macOS 12+（Apple Silicon / Intel）
- Windows 10/11（需在 Windows 机器上构建）
